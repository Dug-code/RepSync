# RepSync

RepSync is a senior project workout tracking application built for Android. The app is designed to help users create workouts, track fitness progress, manage goals, connect with friends, and stay motivated through trophies and notifications.

## Project Overview

RepSync was created as part of a senior project class. The main goal of the app is to give users a simple way to stay organized with their workouts and fitness progress. The project is built mainly in Kotlin and uses Android development tools along with Firebase services.

## Features

- User account creation and login
- Workout creation and tracking
- Exercise and workout logs
- Fitness goals
- Progress tracking
- User profiles
- Friends and social feed features
- Notifications
- Trophies and achievements
- Admin dashboard for moderation
- QR test sheet support

## Tech Stack

- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Firestore
- Android Jetpack components
- ViewBinding
- RecyclerView
- CameraX
- ML Kit barcode scanning
- MPAndroidChart
- Material Calendar View
